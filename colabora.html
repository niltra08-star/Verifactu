Colabora con FacturaIA

FacturaIA es open source y lo construimos entre todos. Descubre como puedes ayudar.

Por que Colaborar

FacturaIA no es el proyecto de una empresa: es un proyecto de la comunidad. Lo mantenemos un equipo reducido de voluntarios que creemos que la facturacion deberia ser gratuita para todos los autonomos. Pero no podemos hacerlo solos.

Cada contribucion, por pequena que sea, ayuda a miles de autonomos espanoles a ahorrar dinero en software de facturacion y a cumplir con sus obligaciones fiscales sin estres. No necesitas ser programador para colaborar: hay muchas formas de ayudar.

Todas las personas que colaboran aparecen en nuestro README de GitHub como agradecimiento publico (a menos que prefieran permanecer anonimas).

Formas de Colaborar

💻

Contribuye Codigo

Si eres desarrollador o estas aprendiendo, puedes contribuir con codigo al proyecto. Tenemos issues etiquetados como "good first issue" especialmente seleccionados para quienes quieren hacer su primera contribucion.

Tecnologias que usamos:

  • Frontend: React + TypeScript
  • Backend: Java + Spring Boot
  • Base de datos: PostgreSQL (via Supabase)
  • Infraestructura: Docker, GitHub Actions
Ver repositorio en GitHub
🐞

Reporta Bugs

Encuentras algo que no funciona como esperas? Reportarlo es una de las formas mas valiosas de contribuir. Un buen reporte de bug incluye:

  • Pasos exactos para reproducir el problema
  • Que esperabas que ocurriera
  • Que ocurrio realmente
  • Captura de pantalla (si aplica)
  • Navegador y sistema operativo

Abre un issue en GitHub con la etiqueta "bug" y lo revisaremos lo antes posible.

💡

Sugiere Funcionalidades

Tienes una idea que haria FacturaIA mejor para ti y para otros autonomos? Compartela. Abre un issue en GitHub con la etiqueta "enhancement" explicando:

  • Que funcionalidad te gustaria ver
  • Que problema resolveria para ti
  • Como te imaginas que funcionaria

Las funcionalidades mas votadas por la comunidad suben en nuestro roadmap de desarrollo.

🌎

Traduce la Aplicacion

Estamos trabajando en traducciones a catalan, gallego, euskera, ingles, frances y portugues. Si hablas alguno de estos idiomas (o cualquier otro) y quieres ayudar con la traduccion de la interfaz:

  • Revisa nuestro proyecto de traduccion en GitHub
  • No necesitas saber programar, solo traducir archivos JSON con textos de la interfaz
  • Cada traduccion ayuda a que FacturaIA llegue a mas autonomos

Contribuir con Codigo: Guia Paso a Paso

Nunca has contribuido a un proyecto open source? No te preocupes. Aqui tienes una guia sencilla para hacer tu primera contribucion a FacturaIA:

1. Configura tu entorno

Necesitaras tener instalado en tu ordenador:

  • Node.js 20 o superior y npm
  • Java 21 o superior y Maven
  • Git
  • Docker (opcional, para desarrollo local completo)

2. Clona el repositorio

Haz un fork del repositorio en GitHub y clonalo localmente. Sigue las instrucciones del archivo CONTRIBUTING.md que encontraras en la raiz del proyecto.

3. Elige un issue

Busca issues etiquetados como "good first issue" en nuestro GitHub. Son tareas seleccionadas especificamente para nuevos colaboradores: bien documentadas, de tamano manejable y con orientacion del equipo si la necesitas.

4. Crea una rama y trabaja

Crea una rama con un nombre descriptivo (ej: feat/mejora-formulario-factura o fix/corregir-calculo-iva). Implementa tu cambio siguiendo nuestras guias de estilo. Asegurate de incluir tests si es posible.

5. Abre un Pull Request

Cuando tengas tu cambio listo, abre un Pull Request contra la rama principal. Describe claramente que has cambiado y por que. Un miembro del equipo lo revisara y te dara feedback.

Si tienes dudas en cualquier paso, puedes preguntar en el issue correspondiente o abrir una discusion en GitHub Discussions. No hay preguntas tontas: todos empezamos alguna vez.

Normas de la Comunidad

Para que colaborar en FacturaIA sea una experiencia positiva para todos, pedimos que sigas estas normas basicas:

  • Respeta a los demas: tratamos a todos los colaboradores con respeto, independientemente de su nivel de experiencia. No toleramos comentarios despectivos, acoso ni discriminacion de ningun tipo.
  • Se constructivo: cuando des feedback, centrate en mejorar el proyecto, no en criticar a las personas. Explica el "por que" detras de tus sugerencias.
  • Paciencia: somos un equipo pequeno y voluntario. A veces tardaremos unos dias en responder a tu issue o revisar tu PR. No nos olvidamos de ti.
  • Reconoce el trabajo ajeno: si utilizas codigo o ideas de otros, atribuye el credito correspondiente.
  • Licencia MIT: al contribuir codigo, aceptas que se publique bajo la misma licencia MIT que el resto del proyecto.

Estas normas estan inspiradas en el Contributor Covenant. Si ves algun comportamiento que las incumple, por favor reportalo a comunidad@facturaia.app.

Otras Formas de Ayudar

💬

Comparte en Redes

Si FacturaIA te ha ayudado, cuentaselo a otros autonomos. Un tweet, un post en LinkedIn o un mensaje en tu grupo de WhatsApp de autonomos puede ayudar a que mas gente descubra que existe una alternativa gratuita. El boca a boca es nuestra principal via de crecimiento.

❤️

Haz una Donacion

Si FacturaIA te ahorra dinero cada mes, considera donar una pequena parte de ese ahorro para mantener el proyecto. Con 3 euros al mes (lo que cuesta un cafe) ayudas a cubrir los servidores. Visita nuestro Ko-Fi para contribuir.

📖

Mejora la Documentacion

La documentacion es el talon de Aquiles de muchos proyectos open source. Si encuentras algo mal explicado, confuso o directamente ausente, puedes proponer mejoras. La documentacion tambien esta en GitHub y acepta Pull Requests.

⭐

Danos una Estrella

Parece una tonteria, pero una estrella en GitHub ayuda muchisimo. Mas estrellas significa mas visibilidad, lo que atrae a mas colaboradores y hace que mas autonomos descubran FacturaIA. Solo necesitas una cuenta de GitHub y un clic.
